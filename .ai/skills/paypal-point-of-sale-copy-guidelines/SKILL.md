# PayPal Point of Sale Copy Guidelines

This skill provides guidelines for writing user-facing copy in PayPal Point of Sale, including UI text, labels, buttons, messages, and documentation.

## Instructions

Follow these guidelines when writing any user-facing text:

1. **Sentence case**: See [sentence-case.md](sentence-case.md) for rules on using sentence case for all UI text

## Key Principles

- Always use sentence case for UI text, not title case
- Keep copy concise and action-oriented
- Use clear, simple language
- Be consistent with WordPress and WooCommerce copy patterns
- Maintain PayPal Point of Sale branding (not iZettle or Zettle)

## Brand References

When referring to the product or related services:

- **Correct**: PayPal Point of Sale, PayPal POS, PayPal Zettle (historical context)
- **Avoid**: iZettle, Zettle by PayPal (unless in historical documentation)
- **Company**: Syde (formerly Inpsyde)

## Technical Communication

- Use active voice when possible
- Be direct and specific about actions
- Avoid jargon unless necessary for technical accuracy
- Provide clear error messages with actionable guidance
