## Rule: Always Use Sentence Case

**Always use sentence case for UI copy, not title case.**

Sentence case means only the first word and proper nouns are capitalized.

## Examples

### Correct - Sentence Case

- "Sync settings"
- "Connect to PayPal POS"
- "Product synchronization"
- "Configure webhook settings"
- "Save changes"
- "View sync log"
- "Enable inventory sync"

### Incorrect - Title Case

- "Sync Settings"
- "Connect To PayPal POS"
- "Product Synchronization"
- "Configure Webhook Settings"
- "Save Changes"
- "View Sync Log"
- "Enable Inventory Sync"

## Exceptions

Sentence case has specific exceptions where capitalization is required:

### 1. Proper Nouns

Always capitalize proper nouns (names of specific products, services, or brands):

**Correct:**

- "Connect with PayPal Point of Sale"
- "Sync to PayPal POS"
- "Import from WooCommerce"
- "Enable WordPress logging"

### 2. Acronyms

Always capitalize acronyms:

**Correct:**

- "Configure API settings"
- "Enter URL"
- "Set up OAuth credentials"
- "Generate SKU"

### 3. Brand Names

Always use the official capitalization for brand names:

**Correct:**

- "PayPal"
- "PayPal Point of Sale"
- "WooCommerce"
- "WordPress"

## Common UI Elements

### Buttons

```text
✅ Correct:
- "Save changes"
- "Sync products"
- "Connect account"
- "Test webhook"

❌ Incorrect:
- "Save Changes"
- "Sync Products"
- "Connect Account"
- "Test Webhook"
```

### Labels

```text
✅ Correct:
- "Sync status"
- "Product mapping"
- "Webhook URL"
- "API credentials"

❌ Incorrect:
- "Sync Status"
- "Product Mapping"
- "Webhook URL" (this is actually correct - URL is an acronym)
- "Api Credentials"
```

### Menu Items

```text
✅ Correct:
- "Settings"
- "Product sync"
- "Webhook logs"
- "Authentication"

❌ Incorrect:
- "Settings" (this one is actually correct - it's a single word)
- "Product Sync"
- "Webhook Logs"
- "Authentication" (this one is also correct - single word)
```

### Headings

```text
✅ Correct:
- "Sync settings"
- "Configure your connection"
- "Advanced options"

❌ Incorrect:
- "Sync Settings"
- "Configure Your Connection"
- "Advanced Options"
```

### Messages and Notifications

```text
✅ Correct:
- "Settings saved successfully"
- "Unable to connect to PayPal POS"
- "Please enter valid API credentials"

❌ Incorrect:
- "Settings Saved Successfully"
- "Unable To Connect To PayPal POS"
- "Please Enter Valid API Credentials"
```

## Why Sentence Case?

More readable, conversational, and modern. Better for accessibility and internationalization.

## Quick Reference

| Element Type | Example |
|--------------|---------|
| Button | "Save changes" |
| Link | "View all products" |
| Label | "API key" |
| Heading | "Sync options" |
| Message | "Product synced successfully" |
| Menu item | "Product settings" |
| Checkbox | "Enable webhooks" |
| Tab | "General settings" |

## When in Doubt

Capitalize only: first word, proper nouns, and acronyms.

Example: "Enable PayPal POS API integration"
